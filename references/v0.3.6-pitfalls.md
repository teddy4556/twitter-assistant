# v0.3.6 4 层 flex 嵌套铁律 — 踩坑

## 问题
v0.3.5 加了 4 个 selector(article video / article img / article [data-testid="tweetPhoto"] / `ScrollSnap-List`)**仍然撑爆**。

## 根因(通过搬参考代码 Clean-up v9.4 §5 才发现)

X 改版后主栏**内部**还有 4 层 flex 嵌套(从外到内):

```
main[role="main"]                                    ← X 自己的 flex 容器
  └─ div[data-testid="primaryColumn"]                ← 主栏(已经改 width)
       └─ div.r-1awozwy.r-18u37iz                    ← 推文卡 flex 容器
            ├─ div.r-1h3ijdo / .r-1e5uvyk             ← 头像 / 头像组
            ├─ div.r-16y2uox                          ← 推文内容容器(默认 flex-grow: 1)
            │    └─ div.r-5zmot / .r-136ojw6         ← 推文文本 + 媒体
            └─ div.r-1loqt21                         ← 更多按钮(可选)
```

**关键事实**:`r-16y2uox` 推文内容容器**默认 `flex-grow: 1`**,**没有任何 `width` 限制**。当容器 `flex-shrink: 0`(主栏被钉死) + 内部 `flex-grow: 1` 的元素**会 grow 超出主栏边界**。姐姐 v0.3.0~v0.3.5 一直在外层 `primaryColumn` / `article img/video` 改,**漏了中间这一层**。

## 修法(搬参考代码 §5 buildLayoutCss)
v0.3.6 搬了 Clean-up v9.4 §5 的 4 个 r-* class 控制,加进 `buildInnerFlexCss()`:

```js
function buildInnerFlexCss() {
  return `
    main div.r-1awozwy.r-18u37iz {
      width: 100% !important; display: flex !important; flex-direction: row !important;
    }
    /* 4 个子 selector:头像 / 头像组 / 文本 / 媒体 */
    main div.r-1awozwy > div { flex-shrink: 0 !important; }
    main div.r-1awozwy > div:nth-child(2) { flex-grow: 1 !important; width: 100% !important; min-width: 0 !important; }
    /* 4 个 r-* 容器拉满 */
    main div.r-1h3ijdo, main div.r-1e5uvyk { width: auto !important; flex-shrink: 0 !important; }
    main div.r-5zmot, main div.r-136ojw6 { width: 100% !important; max-width: 100% !important; }
    main div.r-1loqt21 { flex-shrink: 0 !important; }
    /* utility class max-width 取消 */
    main div[class*="css-175oi2r"] { max-width: 100% !important; }
    /* 推文下方功能列 width 100% */
    main div[role="group"] { width: 100% !important; }
  `;
}
```

## 关键发现
- `r-*` class 是 React 动态 hash,**每次 X 部署都换** — **不能**写死 selector 字符串依赖具体 hash
- 但**结构稳定**:`r-1awozwy` 总是 flex 容器,`r-16y2uox` 总是 grow:1 的内容容器
- **写法**:用 CSS 结构性 selector 拼 class(`.r-1awozwy.r-18u37iz`),即使 hash 变了只要结构还在就生效

## 实战
v0.3.6 上线后,单视频 / 单图 / 多图轮播 / 推文卡片 全部不再撑爆主栏。
