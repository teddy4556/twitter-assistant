# v0.3.34 → v0.3.35 强制 orig 下载 + 大图真值验证 (2026-10-13, 2 版)

## 0. 是什么

这 2 版的真因是 **用户诉求边界**: "我只需要确定下载的不是缩略图", 不是"想要 orig 比 large 大几倍". v0.3.7 起的 `(m.media_url_https || '') + ':orig'` 路径**已经稳**, X 改版后主页 0 张 thumb/small, **永远 large+, 不是缩略图**. v0.3.34 加 console.log 探针让用户/姐姐看到下到的是 large 档, v0.3.35 删探针, 减 console 噪音.

## 1. 关键真值 (10-13 用户 1 行 DevTools + fetch 字节对比验证)

| 字段 | 真值 | 含义 |
|---|---|---|
| `imgCount` (主页推文图数) | **16** | 不是 100+, 姐姐之前担心网络扛不住 100+ 张大图是错的 |
| `name` 参数分布 | `large` (2048x2048) / `medium` (1200x1200) / `large` (1440x1440) | X 改版后默认就是大图 |
| `naturalW × naturalH` | 2048x2048 / 1200x1200 / 1440x1440 | 实际解码尺寸, 都是中大图 |
| `fmt` | `jpg` 100% | 无 webp 兼容问题 |
| `videoCount` (主页) | **0** | 主页无视频, 视频方案不用考虑 |
| `?name=thumb` / `?name=small` (X 主页) | **0 张** | X 改版后主页只用 large/medium, 不发缩略图 |
| `?name=large` vs `:orig` 字节比 | **1.00** (同字节) | X 后端对同一张图 large === orig, 不需要"自动原图"功能 |

## 3. C-extra 真值 (large vs orig 字节对比, 10-13 立)

```js
// C-extra. 媒体字节真值对比 (下载/原图类功能)
(async () => {
  const url = Array.from(document.querySelectorAll('img[src*="pbs.twimg.com/media"]'))[0]?.src;
  if (!url) return 'no img';
  const baseUrl = url.split('?')[0];
  const [l, o] = await Promise.all([
    fetch(`${baseUrl}?format=jpg&name=large`).then(r => r.headers.get('content-length')),
    fetch(`${baseUrl}?format=jpg&name=orig`).then(r => r.headers.get('content-length'))
  ]);
  return JSON.stringify({baseUrl: baseUrl.substring(0, 50), large: parseInt(l), orig: parseInt(o), ratio: (o / l).toFixed(2)});
})()
```

期望真值: `{baseUrl: 'https://pbs.twimg.com/media/HUgpg2Pa4AEhjUt', large: 68741, orig: 68741, ratio: '1.00'}`.

**`ratio 1.00` 是 X 改版后的正常行为, 不是 bug**. 解读: X 后端对同一张图 `?name=large` 和 `:orig` 返回**同一份文件** (X 已经把上传原图 re-encode 到 large 档, 字节 1:1).

## 5. 用户硬偏好 (v0.3.35 锁定, 永久生效)

**用户原话**: "我只需要确定下载的不是缩略图"

**解读**:
- 用户关心"不是缩略图" (>= 1200px 大图), 不关心"orig 跟 large 字节比" (1.00 也行, 因为 large 已经是 X 的最大档)
- **不要**给用户加"自动原图"功能, 油猴改 URL 会触发浏览器重新请求所有图, 30 秒加载完 16 张大图, 用户体感变差
- **不要**纠结 orig 跟 large 字节比 1.00, 这是 X 改版后的正常行为
- **正确做法**: 跑 C-extra 探针证明下载的图是 large 档, 告诉用户"已下到 large, 不是缩略图", 收工
