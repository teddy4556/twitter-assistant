# v0.3.29 → v0.3.33 加宽面板 5 版真因 (2026-10-13, 全部 100% 必读)

**核心真因 (v0.3.29 识破)**: **5 个 `GM_registerMenuCommand` 加宽菜单的 callback 闭包引用 page script 函数** (buildWidthCss / applyWidthStyles / getTimelineWidth 等) → X 改版后油猴 wrapper 在跨 frame postMessage 验证 page script 函数引用 → 引用一旦被 X content.js wrapper 改过, 报 `"invalid name"` 字符串 → 整个 IIFE throw 阻断, `style: 0` (CSS 一次没写进 head)。**v0.3.7 时代 X 改版前 work, v0.3.7 改版后 throw**。

**v0.3.31 修法 = 0 加宽菜单 + 写死 1200px + 同步 applyWidthStyles 1 次** (A 方案, 100% 不会 throw, 跟 v9.4 不冲突)。**v0.3.32 = 悬浮按钮 + HTML 面板** (绕过 GM_registerMenuCommand 验证)。**v0.3.33 = UI 增强** (slider + 数字 input + +/- 步进)。

## v0.3.31-0.3.33 必读铁律 (4 条)

### 1. 油猴 0 加宽菜单铁律 (A 方案核心)

**改 X 改版后任何油猴脚本的加宽面板, 不要调 `GM_registerMenuCommand` 注册加宽菜单**。原因: 5 个 `GM_registerMenuCommand` 的 callback 闭包引用 page script 函数 → X 改版后油猴 wrapper 验证 → throw "invalid name" 阻断整个 IIFE。

**修法 3 选 1**:
- **A 方案 (姐姐 v0.3.31)**: 砍所有加宽菜单, 写死 1200px, 用户不能改
- **B 方案 (姐姐 v0.3.32)**: 改用 1 个 `setTimeout(1500ms)` 之后动态创建 ⚙️ 悬浮按钮 + HTML 面板 (panel 内部用 `GM_setValue` 写值, 不调用 page script 函数注册油猴菜单, 不经油猴 wrapper 验证)
- **C 方案 (未实现)**: 改用 `location.hash` 改宽度 (`#tms_tw=1500`), 不调 GM_*

**A 方案最稳** (5 分钟, 100% 不会 throw, 接受"用户不能改"代价)。**B 方案最完整** (用户能改, 5 个 slider, 姐姐 31 个版本后找到)。

### 2. style 标签 ID 跟 v9.4 一样铁律

**style 标签 ID 用 `tm-timeline-inner-lock`** (跟 v9.4 一样), **不要**用 `tms-width-style` / `tms-layout-style` / 其他。

**为什么**: 油猴 sandbox DevTools 查询 `document.querySelectorAll('style[id^="tms-"]')` → 姐姐 28 版都查不到 v9.4 同款标签 (v9.4 用 `tm-timeline-inner-lock`) → 误判 "CSS 没写" → 改 CSS 改 28 版都没用。

**修法**: style ID 跟 v9.4 一样, DevTools 查询用 `id^="tm-"` 或直接 `tm-timeline-inner-lock`。

### 3. 3 个 DevTools 必查值铁律 (4 个升级到 5 个)

**装油猴脚本改 X 改版后, 第一次测试就贴 1 行 DevTools 4-5 个值回来**:
```js
JSON.stringify({
  main: !!document.querySelector('main[role="main"]'),
  mainW: getComputedStyle(document.querySelector('main[role="main"]')||document.body).width,
  primary: !!document.querySelector('div[data-testid="primaryColumn"]'),
  primaryW: getComputedStyle(document.querySelector('div[data-testid="primaryColumn"]')||document.body).width,
  style: document.querySelectorAll('style[id^="tm-"]').length,  // v0.3.32+ 用 id^="tm-"
  fab: !!document.getElementById('tms-fab')  // v0.3.32+ 测悬浮按钮
})
```

**5 个值真值对照**:
- `main: true` → main 存在
- `mainW` → main 实际宽度 (X 默认 = 100% 视窗, e.g. 1845px)
- `primary: true` → primaryColumn 存在
- `primaryW` → primaryColumn 实际宽度 (X 默认 600px, 加宽后 1200px)
- `style: 1` → style 标签写进 head 了; `style: 0` = throw 阻断或 selector 查不到
- `fab: true` → 悬浮按钮存在

**3 步诊断**:
1. `style: 0` + `mainW: 1845px` + `primaryW: 600px` → **throw 阻断**, 查 console 找 throw 行
2. `style: 1` + `primaryW: 600px` → CSS 写了但没命中, 改 selector
3. `style: 1` + `primaryW: 1200px` → **work, 完结**

**v0.3.32 实测**: `{"main":true,"mainW":"1783px","primary":true,"primaryW":"1252px","style":0,"fab":true}` → main 1783 = 100% 视窗, primary 1252 = 1250 (用户之前设的) + 2px 边框, `style: 0` = 用了 `id^="tms-"` 查 `tm-timeline-inner-lock` 查不到 (style 标签实际存在), fab true = 悬浮按钮有 → 实际 work, 是查询错。

### 4. 1.5s `setTimeout` 创建悬浮按钮铁律 (v0.3.32 加宽 UI)

**改 X 改版后任何油猴脚本加悬浮按钮, 用 `setTimeout(() => { createBtn() }, 1500)`** (1.5s 后再创建)。

**为什么 1.5s**:
- X 改版后 SPA 启动慢, React mount primaryColumn 约 500-1000ms
- 1.5s 后 DOM 稳定, 创建按钮不会被 React 重渲染覆盖
- 立即创建 (`document.addEventListener('DOMContentLoaded', ...)`) 太早, 按钮被 React 重写
- 立即创建 (`(() => { createBtn() })()`) 也太早, document.body 还不存在

**模板** (v0.3.32 验证):
```js
setTimeout(() => {
  if (document.body && !document.getElementById('tms-fab')) {
    const fab = document.createElement('div');
    fab.id = 'tms-fab';
    fab.textContent = '⚙️';
    fab.style.cssText = 'position:fixed;bottom:20px;right:20px;z-index:999998;width:48px;height:48px;border-radius:50%;background:#3b82f6;color:#fff;display:flex;align-items:center;justify-content:center;cursor:pointer;font-size:24px;box-shadow:0 4px 12px rgba(0,0,0,.3);user-select:none;';
    fab.onclick = showWidthPanel;
    document.body.appendChild(fab);
  }
}, 1500);
```

**z-index 999998** (比面板 999999 低 1, 面板覆盖按钮, 但按钮仍能在面板外点击)。

## v0.3.33 UI 增强 (3 种改加宽值的方法, 任选)

**panel 内部用 `sliders()` 辅助函数生成 3 行控件**:
```html
<div style="display:flex;align-items:center;gap:6px">
  <span>时间轴</span>
  <input type="number" min="500" max="1800" value="1200" id="tms-tw-num">  <!-- 直接输入 -->
  <span>px</span>
  <input type="range" min="500" max="1800" value="1200" id="tms-tw">  <!-- 拖动 -->
  <button data-target="tms-tw" data-step="-10">-</button>  <!-- 步进 -10 -->
  <button data-target="tms-tw" data-step="10">+</button>   <!-- 步进 +10 -->
</div>
```

**3 种改法 + 5 个事件**:
- **拖动 slider** → `slider.oninput` 同步 number input
- **点 number input 输入** → `num.oninput` 验证 min/max 后同步 slider; `num.onblur` 修正超范围值
- **点 +/- 按钮** → `btn.onclick` 步进 ±10, 同步 slider + number
- **关闭按钮** → `panel.remove()`
- **应用按钮** → 读 3 个 number input (用户直接输的优先), 调 `GM_setValue` × 6 + `applyWidthStyles()` 重写 CSS

**应用按钮读 number input 而不读 slider** (用户直接输的数优先, 拖动 slider 同步到 number 同步准确)。
